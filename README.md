# 世界树工程 T.Tool

> 当前上传基线：1.0.1 初始可行版本。项目仍在更新中，功能与文档会持续完善。

Windows 本地离线创作工作台，按照项目内「世界树工程设计系统」实现。设计规范、组件与素材保留在设计目录，运行组件在 `src/design/` 中适配为 React 模块。

## 使用

双击 `release/T.Tool-1.0.1-x64-portable.exe` 直接运行，或使用同目录的安装程序安装。运行时不需要 Node.js、Python 或网络连接。

1. 新建工程，选择一个空文件夹；或打开已有工程文件夹。
2. 在项目树创建档案，随意填写名称、类型、标签、正文。档案可以收纳其他档案。
3. 按需要插入文本、数值、倾向轴、雷达图、是/否模块。预设只保存结构，导入会追加模块。
4. 每张关系画布独立保存。可以贴档案引用与便签、编辑有向关系、新建子级、命名快照和回退。
5. 添加的图片复制到工程的 `media/`，JSON 中只保存相对路径。导出生成包含完整工程的 ZIP。

关系文字框可以沿所属连线拖动。鼠标放到四个角落时会显示调整大小的光标，按住拖动即可改变宽高；框的中心留在线上，扩大后文字自动换行。双击仍然编辑关系描述。位置和尺寸会随工程、快照保存，拖动或调整一次可以用「撤销」退回。

已保存工程在停止编辑约 2 秒后自动保存，也可以点击「保存」。关闭或切换工程前，未保存的内容会提示处理。保存失败时状态栏显示原因，并保留未保存状态。

移动、备份或分享工程时，带上整个文件夹：

```text
我的故事/
  project.json
  project.json.bak
  media/
    ……
```

删除图片引用时保留媒体原文件，避免影响其他引用。删除档案会删除它的子档案，画布中的对应引用显示「档案已删除」，关系和历史快照保留。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 新建工程 / 打开工程 | Ctrl+N / Ctrl+O |
| 新建档案 | Ctrl+Shift+N |
| 保存工程 / 另存工程 | Ctrl+S / Ctrl+Shift+S |
| 导出工程 | Ctrl+E |
| 搜索档案 | Ctrl+F |
| 关闭当前档案标签 | Ctrl+W / 鼠标中键 |
| 项目树重命名 / 导航 | F2 / 方向键 |
| 画布撤销 | Ctrl+Z |
| 画布命名快照并保存 | 画布内 Ctrl+S |
| 画布平移 / 缩放 | 滚轮 / Ctrl+滚轮 |

## 开发

使用 Node.js 22 以上版本，不使用 Python，也不修改 Conda base 环境。

```powershell
npm ci
npm run dev
npm run build
npm run verify
npm run verify:ui
npm run package
node scripts/verify-portable.mjs
```

`npm run dev` 同时启动 Vite 和 Electron；`npm start` 启动已构建版本。Windows x64 安装包和便携版输出到 `release/`。

验证打包程序的完整操作流程时，在 PowerShell 中设置 `$env:TTOOL_VERIFY_EXECUTABLE` 为 `release/win-unpacked/世界树工程 T.Tool.exe` 的绝对路径，再运行 `npm run verify:ui`。便携启动检查需要先完成打包。

运行进程启用隔离的预加载 API，通过受限 IPC 读写工程；本地图片通过专用媒体协议读取。UI 无远程字体、远程脚本或联网功能。

## 目录

- `世界树工程设计系统/`：用户提供的原始需求、设计变量、组件实现、接口和 SVG。
- `src/design/`：原组件的桌面适配，补充快照持久化、视口持久化和引用同步。
- `src/App.tsx`：工作台组合与工程操作。
- `src/model.ts`：工程数据结构和结构一致性维护。
- `electron/`：本地读写、安全资源协议、原生文件对话框与窗口生命周期。
- `public/fonts/`：内置 Noto Serif SC 可变字体与 SIL OFL 授权。
- `scripts/verify-*.mjs`：必要的数据安全与完整操作流程验证。
- `docs/工程格式.md`：工程文件格式与恢复说明。

## 设计遵循

颜色、间距、圆角与阴影取自原始 `tokens.css`。原始组件中独立尺寸换成等值的变量表达式；画布方块尺寸与几何计算保留设计规定。控件使用系统黑体，创作者内容使用内置宋体；所有操作图标均来自原设计 SVG 并配文字。

按设计保留「双击引用方块跳转档案暂未开放」：没有子级时会显示提示；有子级时双击收起或展开其子孙。

最终验证记录见 `docs/验收记录.md`。
