# ProjectTree

无限层级的项目树，用来收纳和排序档案；拖拽时可以放进任意档案的上方、下方或内部。

- 数据是 `TreeNode[]`（id、name、type、children），受控或非受控都可以。`onSelect` 用来在编辑区打开档案。
- 内置右键菜单：新建同级档案、新建子档案、重命名、删除。删除前请传 `onRequestDelete` 弹出 Dialog 确认（有子档案时一并说明数量）。
- 拖放分三区：上 28% 放到上方，下 28% 放到下方，中间放进内部；不能拖进自己的子孙里。悬停在折叠的文件夹上 0.65 秒会自动展开。
- 行不换行、不压缩：层级很深或名字很长时整树横向滚动。
- 键盘：↑↓ 移动，← → 折叠/展开，F2 重命名，Enter 打开，Shift+F10 打开菜单。
- 不校验结构：角色可以放在世界观下面，这是设计如此。
- `ProjectTree.utils` 提供 find、move、insert、remove、update、count 这些纯函数。
