# RelationCanvas

关系画布：一张独立的空白拼贴板，用来摆档案引用和便签，拉线写关系，还能存快照、随时回退。

- 传 `name`、`defaultGraph`（nodes、edges）、`archives`（可引用的档案）、`onChange`。每张画布各用一个实例，切换画布时用 `key` 重新挂载。
- 添加：工具栏“引用档案 / 便签”，或在空白处右键（可以直接贴在指针位置）。
- 连线：从方块右侧圆点拖到另一个方块；或打开“连线”模式，依次点起点和终点。新线建好立刻弹出描述输入框，描述可以留空。
- 规则：同一方向重复连线会被拦截（选中已有那条，并给出引导语）；反向连线允许，两条平行错开。
- 子级：右键“新建子级”会生成一张用灰色虚线连接的便签；双击父方块收起或展开它的子孙。
- 画布永远不改档案：引用方块改名只改显示名，“从画布移除”不会删除档案。
- 视口：滚轮平移，Ctrl+滚轮缩放，横竖滚动条可拖动，“适应”一键看全；任何缩放下都能滑到每个方块。
- 历史：撤销（Ctrl+Z）一步一步退；存快照（Ctrl+S）和历史快照是可回退的保存点；回退前会自动存一条快照。没有“重做”。
- 嵌在长页面里时设 `wheelRequiresFocus`，避免滚轮被画布抢走。
