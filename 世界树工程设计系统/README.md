世界树工程 T.Tool 是给小说、OC、世界观创作者用的 Windows 本地离线工作台。一个故事就是一个工程，里面有档案、积木模块和多张关系画布。软件只提供容器，不替创作者规定写法。界面因此要像一张干净的白纸：安静、浅色、有层次，把注意力留给创作者自己的文字。

客户原文到设计决定的逐条对应，见“需求解读”一节。

## 四条设计原则

1. **容器退后，内容在前。** 软件的部分（按钮、菜单、面板标题）一律用黑体 `sans` 和中性灰。创作者写的东西（档案名、正文、画布方块名、预设名）一律用宋体 `serif`。
2. **没有必填。** 不出现红色星号，不出现“请填写”。空状态要说明“需要时再加”，而不是催促。
3. **画布永远不改档案。** 凡是画布上的移除、改名操作，文案都要说清楚影响范围：“从画布移除（不删档案）”“档案：林晚”。
4. **每个按钮都有字。** 图标从不单独出现，`IconButton` 的文字是必填项。唯一的例外是标签页和标签胶囊上的 ×：它们属于元素本身，悬停时提示“关闭”或“移除”。

## 文案

- 用“你”，不用“您”。语气平实、简短，不用感叹号，界面里不用 emoji。
- 按钮写成 2–6 个字的动词短语：“新建档案”“存快照”“回退到此”“导入到当前档案”“从画布移除”。
- 统一用词。下表是固定术语，界面里不要换成近义词：

| 用这个 | 不要用 | 指什么 |
| --- | --- | --- |
| 档案 | 节点、条目、卡片 | 项目树里的一个内容单位 |
| 项目树 | 目录、文件夹树 | 左侧的层级收纳 |
| 模块 | 字段、组件、拼图 | 档案里可插拔的积木 |
| 预设 | 模板 | 存下来的模块结构 |
| 关系画布 | 关系网、导图 | 一张独立的拼贴画布 |
| 方块 | 节点、卡片 | 画布上的一个元素：引用方块 / 便签 |
| 关系 | 边、连线关系 | 两个方块之间的有向连线 |
| 快照 | 版本、备份 | 画布某一时刻的保存状态 |

- 提示语要先说结果，再说下一步，例如：
  - 重复连线：“‘林晚 → 沈既白’已经有一条关系了。同一方向的多重关系，请写进这条线的描述里；差别很大的话，可以新建一张画布。”
  - 回退：“已回退到‘第一幕定稿’。回退前的画布已自动存成一条快照。”
  - 移除：“已从画布移除‘林晚’。档案本身没有被删除。”
- 数字用阿拉伯数字，标点用全角。

## 颜色

浅色“纸面”是默认主题。所有底色都是近白的浅暖灰，最深的一层也只是 `bg`（#f4f3ef）。

- **层次**，由外到内：`bg` 用于应用外框（顶部工具栏、状态栏、标签栏）→ `surface` 用于面板（项目树、编辑页）→ `surface-raised` 用于纯白的浮起层（模块卡片、画布方块、菜单、对话框）。`surface-sunken` 只用于凹下去的东西：滑轨、计数徽标、标签胶囊。
- **文字**：正文、标题用 `ink`；次要信息、类型徽标、图标按钮的文字用 `ink-muted`。两者在所有底色上都不低于 4.5:1。`ink-disabled` 只用于禁用状态。
- **苔绿 `moss` 是唯一的操作色**：主按钮、选中、拖放落点、焦点环、链接都用它。每个区域最多一个 `primary` 按钮。选中行和选中标签的底色用 `moss-soft`。
- **苔绿填充上的文字用 `on-moss`**，不要写死白色，因为暗色主题里它是深色。
- **茜红 `thread` 只给关系线和箭头用**，不要拿它报错或做强调。
- **便签**用 `sticky`（浅黄），无描边，靠 `shadow-sm` 浮起。
- **状态色**：提醒用 `warn` 文字配 `warn-soft` 底；危险操作用 `danger`。两种状态都必须配文字或图标，不能只靠颜色区分。
- **描边**：结构分隔用 `line`；需要被找到的输入框边框用 `line-strong`（不低于 3:1）；画布方块用更淡的 `card-edge`。
- 暗色“夜读”主题用的是同一套 token 名，组件里不要写死任何颜色值。

## 字体

| 用途 | 样式 | 字族 |
| --- | --- | --- |
| 档案名 | `doc-title` 26/34 粗 | 宋体 |
| 画布名、预设名 | `doc-heading` 18/28 | 宋体 |
| 正文、文本模块 | `doc-prose` 15/28 | 宋体 |
| 画布方块名 | `card-title` 14–15/20 | 宋体 |
| 面板、对话框标题 | `ui-title` 16/24 | 黑体 |
| 界面默认文字 | `ui-body` 14/22 | 黑体 |
| 模块标题、强调 | `ui-strong` 14/22 | 黑体 |
| 按钮文字说明、字段标签 | `ui-label` 12/16 | 黑体 |
| 提示、元信息 | `ui-caption` 12/18 | 黑体 |
| 数值、百分比、分值 | `data` 13/20 | 等宽 |
| ID、快照时间、缩放比例 | `data-sm` 11/16 | 等宽 |

- 宋体用 Noto Serif SC（SIL OFL 授权）。桌面端是离线软件，**字体文件必须随安装包内置**，不能依赖联网加载。缺字时依次回退到思源宋体、宋体。
- 黑体优先用系统自带的 Segoe UI 和 Microsoft YaHei UI，不另外打包。
- 中文不用斜体。不要用字重以外的方式强调。

## 间距与布局

- 4px 基准：`space-1` 4 · `space-2` 8 · `space-3` 12 · `space-4` 16 · `space-5` 20 · `space-6` 24 · `space-8` 32 · `space-10` 40。
- 工作台骨架：顶部工具栏 `size-toolbar` 60px（图标在上、文字在下）；左侧面板 `size-sidebar` 264px；标签栏 `size-tab` 36px；底部状态栏 `size-statusbar` 28px。
- 档案编辑页内容最宽 `size-page` 760px，居中，左右留白 `space-8`。从上到下依次是：档案头 → 正文 → 模块 → 画布引用，各区之间隔 `space-6`。
- 模块之间隔 `space-4`；模块内边距 16/20px；行与行之间隔 6px。
- 控件高度：默认 `size-control` 32px；模块头部和行内的小按钮用 `size-control-sm` 26px；树行和菜单项用 `size-row` 28px。

## 圆角、描边与阴影

- 圆角：`radius-sm` 6px 用于按钮、输入框、树行、菜单项；`radius-md` 10px 用于模块卡片、画布方块、预设卡片；`radius-lg` 14px 用于对话框和画布外框；`radius-full` 只用于计数徽标、关系标签胶囊、画布名牌。
- 质感来自“极淡的描边 + 两层低透明度阴影”，而不是粗边框或大面积色块。
  - `shadow-sm` 给静止的卡片、模块、关系标签。
  - `shadow-md` 给悬停和拖动中的方块。
  - `shadow-lg` 给菜单、对话框等浮层。
- 不用渐变，不用彩色的左侧描边条，不用内阴影。

## 状态与动效

- 悬停：底色换成 `surface-sunken`，文字从 `ink-muted` 变成 `ink`。
- 选中：`moss-soft` 底；画布方块用 `ring-select` 2px 苔绿环。
- 键盘焦点：`focus-ring`，即 2px 底色间隙加 2px 实心苔绿环，在所有底色上都不低于 3:1。
- 拖放落点：上方或下方显示苔绿插入线（带一个圆点标出层级），放进内部时整行用 `moss-soft` 并出现“成为子档案”胶囊。
- 禁用：`ink-disabled`，不降低整个控件的不透明度（主按钮除外）。
- 动效：悬停和颜色变化 120ms，阴影变化 150ms，统一 ease-out。不用弹跳。开启“减少动态效果”时全部关闭。

## 关系画布

- 画布底板是 `canvas`，上面铺 20px 间距的 `canvas-dot` 细点阵，点阵随缩放和平移移动。
- 方块有两种，尺寸固定：
  - **引用方块** 172×64：白底，右上角带回形针标记；第一行是宋体名称，第二行是类型，改过名时显示“档案：原名”。
  - **便签** 164×84：`sticky` 底，黑体正文最多三行。
- 关系线是 1.5px 的 `thread`，带实心箭头；选中后变成 2.5px 的 `moss`。
- 关系描述是带阴影的胶囊标签，最宽 136px，超出显示省略号；单条线的标签在中点，一对反向线的标签各自落在 42% 处。
- 反向的一对关系向两侧各偏 14px 平行显示；同一方向的重复关系一律拦截。
- 从属关系（新建子级）用 1.25px 的 `ink-muted` 虚线，不带箭头，和关系线明确区分。
- 视口：滚轮平移，Ctrl+滚轮缩放（25%–300%）；任何缩放下都能把每个方块滑进视口；横竖滚动条可拖动。
- 历史：撤销（Ctrl+Z）只管本次编辑的每一步；快照（Ctrl+S）是可以命名、随时回退的保存点。没有“重做”。

## 图标

- 自绘线性图标：24 栅格、1.6 描边、圆头圆角，用 `currentColor` 着色，共 41 个。
- 组件里用 `<Icon name="…">`；独立的 SVG 文件在素材的 Icons 分组，墨色是 `ink` 的 #23201b。
- 模块类型各有一个图标：文本 `mod-text`、数值 `mod-number`、倾向轴 `mod-axis`（就是 I 形游标）、雷达图 `mod-radar`、是/否 `mod-bool`。
- 档案引用的标记统一用 `paperclip`，不要用 📎 emoji。

## 标识

客户没有提供 Logo。在提供之前，产品名用宋体粗体文字“世界树工程”显示，不要自行绘制标志。

## 使用组件

组件在 `components/bundle.js`，挂在 `window.TTool` 下，依赖 React 18。全部组件都同时支持受控（`value` / `onChange`）和非受控（`defaultValue`）两种用法。各组件的接口见 `components/index.d.ts` 和各自的说明。完整的组合示例见“Workbench”页面：项目树、多开档案、模块、预设库、画布引用跳转、多张画布。
