# 世界树工程 T.Tool 验收记录

## 1.0.1：关系文字框拖动与缩放

根据用户新增要求，关系文字框支持沿所属连线拖动，以及四角调整宽高；扩大后多行显示，框的中心保持在线上。双击仍可编辑关系描述。位置、宽高使用三个可选字段保存，旧工程按原设计显示，不需要迁移。

生产构建与关键存储验证通过。对最终打包程序运行实际桌面流程，12 组检查全部通过，补验了缩放后的斜线拖动、反向标签互不影响、右下扩大、左上缩小、完整多行文字、每次拖动／缩放单步撤销、双击编辑、调转方向保持自定义位置、方块移动后跟随连线、快照保存与回退、另存及重启恢复。快照保留历史尺寸，清除当前尺寸不会被未知字段合并重新带回；错误比例、非数值、无穷值和超限尺寸被文件层拒绝。最终便携 EXE 的解压启动、画布和内置字体检查也通过，无页面错误或 HTTP 请求。

内存检查使用实际组件的指针与状态处理函数，React hooks 的状态通知替换为无操作，不渲染 DOM、传 IPC 或写磁盘：5,000 方块、10,000 关系，75 次操作、2,250 指针帧共 200.5 ms；采样堆峰值比基线增加 20.8 MiB，GC 后保留增量 4.85 MiB。每帧只复制关系数组和改动的关系对象，方块共享；每次操作只记录一个撤销状态，历史最多 60 步。持有成本随关系数和撤销步数增长，测量不代表整个桌面应用的峰值。

## 1.0.0：首次交付

验收日期：2026-10-08。环境：本机 Windows 11 x64（10.0.26200），Node.js 24.16.0，Electron 41.0.2，React 18.3.1。交付的是 Windows x64 安装包和便携版；运行不需要开发环境。

## 设计与功能

实现依据是项目内「世界树工程设计系统」的 `requirements.md`、`README.md`、`tokens.css`、组件接口、组件说明及 Workbench 示例。设计规范、组件与素材保留在设计目录，组件适配代码位于 `src/design/`。

- 使用原设计的纸面／夜读主题、布局、宋体内容、黑体控件、SVG 图标与带文字操作按钮。颜色、间距、圆角及阴影来自设计变量。Noto Serif SC 和 OFL 授权随软件打包。
- 自由类型档案、父档案正文、多开标签、搜索、项目树三区拖放及悬停展开；五种模块、排序及只存结构的预设。
- 独立的多张关系画布、档案引用与便签、有向关系、同向重复拦截、反向平行错开、子级虚线与收展、撤销、命名快照和回退前自动快照。
- 新建、打开、自动／手动保存、另存、带图片的完整 ZIP 导出。一个工程对应 `project.json` 和 `media/`；图片使用相对路径。
- 原子保存、有效备份、损坏恢复、工程锁、外部修改检测、旧格式迁移及未知字段保留。

按设计保留的行为：引用方块双击跳转档案暂未开放；有子级时双击收展。删除档案后，画布引用变灰，关系与历史快照保留。删除图片引用会保留 `media/` 原文件。

## 内存测量与范围

| 场景 | 观测结果 | 假设与限制 |
| --- | --- | --- |
| 48 MB 图片流式导入并导出 ZIP | 最近一次 0.15 秒，RSS 峰值比起点增加 27.1 MB；多次运行为 16.3–27.8 MB | 尾部填充的稀疏 PNG；单个 Node 文件处理进程，非真实照片解码或整个 Electron 峰值 |
| 25,000 个档案与画布引用的单项改名 | 最近一次 8.6 ms，采样堆增量 4.28 MiB | 包含临时索引；未变对象共享引用；不含 DOM 渲染和进程峰值 |
| 5,000 方块、10,000 关系、2,250 拖动帧的历史处理 | 组件验证中约 67 ms，GC 后保留堆增量约 2.43 MB | 纯状态与历史计算，撤销最多 60 步；不包含 React DOM、磁盘和持久化快照体积 |

媒体复制和 ZIP 使用有界流；图片头检查最多读取 1 MiB。工程 JSON 仍需全量解析、IPC 传输和序列化，多张图片解码、很多可见方块及长期累积的命名快照会增加内存和文件体积；未进行整个应用的极限规模压力测试。

当前保护范围：JSON 最多 64 MiB、项目树深度最多 128、单张图片最多 50 MiB 和 4,000 万像素。媒体缺失时允许打开文字并保留路径，但要恢复缺失文件或移除对应引用后再保存。
